# Ревью и планы исправлений

Каждый цикл — папка с датой, внутри два файла:

- **`review.md`** — что найдено на конкретном коммите. После передачи не правится: это фиксация состояния.
- **`plan.md`** — живой документ: задачи с галочками, таблица решений, возражения, хэши коммитов.

Следующий цикл — новая папка рядом. Повторное ревью в тот же день дописывается в папку дня с пометкой «найдено вторым проходом».

## Номера

Сквозные между циклами: новый пункт продолжает наибольший номер своего префикса во всех `review.md` и `plan.md`. Номер — в начале сообщения коммита.

| Префикс | Что |
|---|---|
| `ARCH` | системная причина нескольких находок |
| `BUG` | ошибка прототипа или его расхождение с требованиями |
| `REQ` | противоречие или пробел в требованиях |
| `DOC` | неточность в README и сопроводительных документах |
| `DATA` | демо-данные противоречат требованиям или сами себе |
| `PROC` | процесс: коммиты, проверки, договорённости |

## Важность

- **[блокер]** — не работает основной сценарий;
- **[высокий]** — ошибка в модели или в частом сценарии, тихая порча данных;
- **[средний]** — заметная ошибка или пробел, есть обходной путь;
- **[низкий]** — неточность, на работу не влияет.
