# Журнал изменений ТЗ

Действующее ТЗ — [ТЗ_LicensePlateRecognition_Интеллект_X.md](ТЗ_LicensePlateRecognition_Интеллект_X.md). Номер версии в его шапке совпадает с последней записью здесь.

Как вести: новая запись сверху; в записи — версия, дата, что изменилось (идентификаторы требований) и основание — номер пункта плана ревью или решения (`REQ-01`, решение 2026-11-02). Удалённое требование не удаляется из ТЗ молча: строка остаётся с пометкой «исключено, <основание>», идентификатор не переиспользуется.
