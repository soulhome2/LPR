# LPR — LicensePlateRecognition для Интеллект X

Вертикальное решение ITV для ПК **Интеллект X**: распознавание государственных регистрационных знаков (ГРЗ) и атрибутов транспортных средств на детекторах **RoadAR** (DetectorPack) и прикладная аналитика поверх них — контроль доступа на КПП, парковки, списки контроля и оповещения, поиск и расследования, скорость и нарушения на территории, контроль качества распознавания.

## Сценарии

| Сценарий | Что даёт |
|---|---|
| КПП и контроль доступа ТС | Автопропуск по спискам, гостевые пропуска, решение оператора, учёт ТС на территории, время цикла «въезд — выезд» |
| Парковки | Заполненность, время стоянки, превышение лимита, частые посетители |
| Безопасность территории | Розыск и «чёрные» списки, оповещения в реальном времени, сверка оператором |
| Расследования | Поиск по части ГРЗ и атрибутам, маршрут, общие ГРЗ, совместное движение, двойники, доказательный пакет |
| Нарушения (расширение) | Превышение скорости в зоне, движение против направления, стоянка в запрещённой зоне |

## Прототип

`prototypes/index.html` — самодостаточный файл: открывается в браузере без сервера и интернета. Стиль — ONE PSIM Prototype Kit (визуальное семейство ITV), светлая и тёмная темы. Данные — фикстура.

Экраны: рабочее место оператора КПП · срабатывания · журнал проездов и карточка ТС · расследования · списки контроля · территория и парковки · каналы и качество распознавания · нарушения.

## Технологическая основа

- Платформа: ПК Интеллект X (ITV)
- Движок: RoadAR — «Распознавание ГРЗ RR», «— Парковка», «— Поиск в архиве», «Распознавание ТС RR»
- Хранилище: PostgreSQL (уточняется), видео — ссылками на архив Интеллект X
- Интеграции: REST API, Webhook, MQTT, импорт CSV/XLSX, СКУД, 1С/ERP
